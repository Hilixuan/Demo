## 一、业务目标与范围

文书智写是国青企业 Agent 系统中承接“材料管理 → 文书生成 → AI 调优 → 智能评分”的核心模块，服务申报顾问与项目经理完成专项申报书从资料到定稿的全流程制作。模块以企业申报项目为工作单元，将资料准备、文书起草、AI 校验与人工决策串成闭环，避免文书内容脱离真实证据、资金口径矛盾或资料缺失导致返工。

**核心用户**

- 申报顾问：负责日常资料整理、文书生成、按 AI 建议调优并确认修改。
- 项目经理：查看项目进度与告警，审批关键修改、导出与归档。
- 系统管理员：维护权限、审计与导出审批（复用系统设置模块）。

**成功度量**

- 文书初稿生成时间从小时级降至分钟级（目标：单项目初稿 ≤ 15 分钟）。
- AI 评分与人工评审结论一致率 ≥ 85%（以人工终审为准）。
- 因资料缺失或口径矛盾导致的退回次数下降 ≥ 40%。
- 关键操作（修改、导出、归档）100% 留痕可追溯。

**本期范围**

- 项目管理：按年份组织项目、进度与告警展示、归档与只读。
- 企业资料库：目录化文件管理、AI 识别缺失与风险。
- 文书生成：模板大纲、对话式生成、资料缺口标注、编辑存档与版本历史。
- AI 调优：雷同片段横向对比、定位调优、对话式局部微调。
- 智能评分：五维 AI 评分、全文校对、人工确认修改与收尾。

**不在本期（见第八章）**

## 二、页面关系 / 信息结构

```
文书智写（#/materials）
├─ 项目管理：项目年份分组 → 项目卡片（进度/完整度/评分/告警）
│  └─ 项目工作台
│     ├─ 企业资料库：文件目录 + Agent 资料识别
│     ├─ 文书智写：一级目录 + 文书主体 + 对话生成
│     ├─ AI调优：草稿编辑 + 横向对比
│     └─ 智能评分：终稿预览 + AI评分 + AI校对
└─ 全局动作：新增企业项目、查看全部 PRD 标注、导出/归档
```

- 项目管理页是模块入口；选择项目后进入项目工作台。
- 工作台四个页签共享同一项目上下文，切换页签不丢失草稿状态。
- 每个功能卡片头部显示 PRD 数字小点：蓝色为功能需求、橘黄色为 Agent 需求；点击小点打开需求详情抽屉。
- 工作台头部提供「全部 PRD」入口，按五个子模块分组展示 17 条需求。

## 四、交互逻辑（含 AI 决策流程）

| 页面/触发入口 | 前置条件 | AI 推理步骤 | 操作与校验 | 状态变化/反馈 |
|---------------|----------|------------|------------|---------------|
| 项目管理 → 新增企业项目 | 管理员或项目经理权限 | 解析目录索引并归类文件 | 填写企业、项目类型与描述 | 项目创建成功，进入解析队列 |
| 企业资料库 → AI识别 | 已上传资料目录 | 扫描目录 → 抽取合同/发票/照片元数据 → 比对设备索引表 → 输出洞察 | 逐条标记已解决 | 洞察从工作清单移除 |
| 文书智写 → 生成文书 | 资料已入库、模板已选 | 读取资料库 → 匹配模板 → 校验章节完整度 → 生成主体 → 标注证据缺口 → 写缓存 | 展示步骤进度 | 草稿生成，缺口标签可见 |
| 文书智写 → 对话微调 | 草稿已生成 | 解析调优要求 → 更新对应章节 | 输入要求后发送 | 草稿更新并提示 |
| AI调优 → 定位/确认修改 | Agent 已输出雷同建议 | 扫描相似度与特色缺口 | 定位段落、人工确认修改 | 草稿更新，建议保留 |
| 智能评分 → 同意修改 | AI 校对已输出问题 | 定位问题 → 应用建议表述 | 手动修改/针对微调/同意修改 | 条目从问题列表移除 |
| 智能评分 → 导出/归档 | 问题全部处理 | — | 权限校验、导出审批 | 文档导出留痕，项目归档只读 |

**AI 决策边界**

- Agent 只能生成、建议、评分与校验，不能代替人工立项、授权修改、导出与归档。
- 评分与校对结果仅作参考，最终以人工评审为准。
- AI 输出必须附依据：文件名命中、内容比对、有效期规则或引用片段。
- 归档项目只读，任何修改类操作禁用；重启制作由用户显式发起。

## 五、业务规则

| 规则项 | 规则口径 | AI 相关 | 权限/边界 |
|--------|----------|---------|-----------|
| 项目组织 | 按年份分组，组内按更新时间倒序 | — | 项目可见范围按角色授权 |
| 完整度 | 按章节统计已具备/缺失资料占比 | Agent 判定章节完整度 | — |

## 六、接口与数据（功能级，可选）

- 企业资料库输入：目录索引、文件元数据（名称、类型、大小、识别状态）。
- 文书生成输入：专项政策、企业资料包、文书模板、用户生成要求；输出：章节正文、引用片段、资料缺口清单。
- AI 评分输入：文书全文与评分标准；输出：总分、五维得分、问题清单（级别/位置/描述/建议）。
- 版本历史输入：存档快照；输出：版本号、时间、说明。
- 导出链路：导出请求 → 权限校验 → 管理员审批 → 留痕记录。

## 七、AI 模型与 Agent 设计

- **Agent 角色**：申报材料 Agent 承担资料识别、文书生成、缺口检测、雷同对比、评分与校对六类任务。
- **模型选型建议**：文书生成与调优优先选用长上下文、中文写作能力强的生成式大模型；资料识别与口径校验采用结构化抽取模型 + 规则校验（文件名、有效期、金额）双通道，降低幻觉风险。
- **Prompt 设计要点**：生成类任务注入专项政策、企业资料、模板结构与评分标准；所有输出必须给出引用来源或判定依据。
- **工具调用链**：知识库检索 → 文件元数据解析 → 模板匹配 → 章节生成 → 证据校验 → 草稿缓存。
- **人机协同**：生成、建议、评分 = Human-on-the-loop；修改、导出、归档 = Human-in-the-loop。
- **评估指标**：资料缺口召回率、金额口径一致率、文书评分与人工评审一致率、修改建议采纳率。

## 八、不在本期

- 移动端文书编辑与离线生成。
- 多语言申报文书与自动翻译。
- 自动提交申报与线上申报系统对接。
- 多企业批量文书生成。
- 自动生成申报附件压缩包并直传政务平台。

## 九、核心用户故事

1. 作为申报顾问，我希望项目资料按目录自动识别并提示缺失项，以便生成文书前补齐证据链。
2. 作为申报顾问，我希望基于政策、资料包与模板对话式生成申报书初稿，以便快速获得可微调的底稿。
3. 作为项目经理，我希望 AI 评分与校对问题逐条由人工确认后再定稿归档，以便保证文书口径与真实性可控。
